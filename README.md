# Arsit-FaceDetection

> 基于 OpenCV 的实时人脸检测系统 — Arsit 情感陪伴项目 V0.1

## 项目简介

Arsit（Artificial + Sit，意为"陪伴在你身边"）是一个面向情感陪伴方向的智能交互项目。本仓库为 Arsit 的计算机视觉基础模块，实现了基于摄像头的**实时人脸检测与目标框选**功能。

本项目作为齐鲁工业大学 RoboMaster 算法组提前批考核作品提交。

## 技术栈

- **语言**：C++
- **视觉库**：OpenCV 4.10.0
- **检测算法**：Haar 级联分类器（haarcascade_frontalface_default）
- **开发环境**：Visual Studio 2022 / Windows 11

## 功能特性

- ✅ 实时摄像头画面捕获（640x480，30fps）
- ✅ 人脸自动检测与红色边界框标注
- ✅ 支持多人人脸同时检测
- ✅ ESC 键优雅退出

## 运行方式

### 环境要求
- Windows 系统
- OpenCV 4.x 已安装并配置环境变量
- Visual Studio（支持 C++ 开发）

### 运行步骤
1. 克隆本仓库
2. 用 Visual Studio 打开项目（或新建项目并引入 `main.cpp`）
3. 配置 OpenCV 包含目录、库目录和附加依赖项
4. 修改代码中 Haar 级联分类器 XML 文件路径为你本地路径
5. 编译运行，按 ESC 退出
